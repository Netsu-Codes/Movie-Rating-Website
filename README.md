# Movie-Rating-Website
This is a website where I rank movie so other people can find a fun watch! I normally struggle to find movies on my own and the movie rankings I find online are normally not good so I made this website to help others with the same problem! 
## Details:
A website for people to look for movie recommendations. It has my personal rating, parent guides, a small overview/ summary from IMDb that I paraphrased, this way people can read a quick, free from spoilers summary. If you click the posters it takes you to the specific section on the movie page. You can use the navigation to move between home and movie page!
